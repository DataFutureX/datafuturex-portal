# 技术门户审核核对表

## 定位与首屏

- [ ] 10 秒内能说出门户提供什么
- [ ] 首屏无统计条/日程/多促销块
- [ ] 主 CTA 明确（文档或控制台）
- [ ] 去掉导航后仍能识别品牌/产品

## 信息架构与导航

- [ ] 主导航项 ≤ 6，按任务聚合
- [ ] 产品/文档/示例/支持路径清晰
- [ ] 深页有面包屑或等价位置指示
- [ ] 无仅靠分享链接才能到达的关键页
- [ ] 控制台等外链行为一致且可辨

## 文档

- [ ] 存在可用的快速开始（步骤 + 可复制示例）
- [ ] 指南与 API 参考分离且互链
- [ ] 侧边栏与路由同步，无大量孤儿文
- [ ] 代码块无真实密钥；错误场景有说明
- [ ] 版本/弃用信息可见

## 搜索与发现

- [ ] 桌面与移动均可发起搜索
- [ ] 产品名与常见任务词可命中
- [ ] 空结果有后退路径（热门文档/支持）

## 一致性

- [ ] 同一概念全站同一名称
- [ ] 导航文案与页面 H1 语义一致
- [ ] 按钮层级（主/次）一致

## 无障碍与性能

- [ ] 每页一个 h1；标题不跳级
- [ ] 主流程可键盘完成
- [ ] 图标按钮有 accessible name
- [ ] 首屏无明显巨大无压缩图或阻塞脚本
- [ ] 375px 无横向滚动、可点目标足够
