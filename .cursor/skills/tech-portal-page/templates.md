# 门户页面模板

## 首页文案骨架

```text
品牌名
一句话：为谁解决什么问题（≤ 30 字）
主 CTA：阅读文档 | 次 CTA：打开控制台
能力入口：3–8 个核心产品（名称 + 一行说明 + 链到落地页或文档）
```

## 能力落地页骨架

```markdown
# {产品名}

{一句话：做什么}

## 适用场景
- …

## 核心能力
- …

## 快速开始
1. …
2. …

[查看文档](/docs/...) · [打开控制台](...)
```

## 文档壳结构

```text
Header（Logo、主导航、搜索、控制台）
├─ DocSidebar（章节树、当前高亮）
├─ Article（h1、正文、复制代码、末尾相关链接）
└─ Toc（可选，当前页标题锚点）
```

## CTA 文案

| 场景 | 主 CTA | 次 CTA |
|---|---|---|
| 首页 | 阅读文档 | 打开控制台 |
| 能力页 | 快速开始 | API 参考 |
| 文档末 | 下一篇 | 相关示例 |
