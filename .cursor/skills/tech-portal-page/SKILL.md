# 技术门户页面构建

## 何时使用

- 新建或改版首页、产品/能力页、文档布局、示例列表
- 调整导航、Hero、能力入口、CTA

## 工作流

复制并跟踪：

```
页面任务:
- [ ] 1. 定页面类型与单一目标
- [ ] 2. 定信息层级（首屏预算）
- [ ] 3. 对齐导航与路由
- [ ] 4. 实现布局与内容槽
- [ ] 5. 无障碍与响应式自检
```

### 1. 定页面类型

| 类型 | 单一目标 | 首屏只保留 |
|---|---|---|
| 首页 | 理解门户并进入文档/产品 | 品牌、一句价值、1 组 CTA、能力入口 |
| 能力落地页 | 决定是否采用并开始 | 名称、是什么、关键能力、快速开始 CTA |
| 文档壳 | 阅读与跳转文档 | 顶栏、侧导、正文区 |
| 列表/目录 | 筛选并进入详情 | 搜索/筛选 + 结果 |

若目标超过一个，拆成多个页面或明确主次（主 CTA 唯一）。

### 2. 首屏预算（硬限制）

允许：品牌/标题、一句支持文案、一组 CTA（主+次）、一个主视觉或能力入口带。

禁止塞进首屏：统计条、日程、新闻列表、多枚徽章、地址/联系块、促销贴纸。

### 3. 对齐导航与路由

- 新页必须能从主导航或首页入口到达
- 遵循项目路由约定；无约定时用 `/products/[slug]`、`/docs/[...slug]` 等常见结构
- 外链标明并 `target="_blank"` + `rel="noopener noreferrer"`

### 4. 实现要点

- 复用现有 Header/Footer/DocSidebar，禁止复制粘贴壳层
- 内容与壳分离（MDX/CMS/配置驱动能力列表）
- 卡片仅用于可点击入口；装饰性包裹去掉边框阴影亦可理解则删掉
- 有设计系统则用 token；否则用 CSS 变量统一间距与色板
- 保留既有视觉语言，不引入无关的紫渐变/通用 AI 审美

### 5. 自检

- [ ] 去掉导航后，首屏仍能识别是本产品门户
- [ ] 主 CTA 指向真实可用路径
- [ ] 375px 下无信息丢失、可点区域足够大
- [ ] 一个 `h1`；链接非 div 点击

## 输出约定

改码时同步给出：页面目标一句话、路由、主 CTA 指向。大改版先列信息架构再写代码。
