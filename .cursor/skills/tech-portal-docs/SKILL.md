# 技术门户文档体系

## 何时使用

- 规划文档树、接入 MDX/内容库、做快速开始
- 区分「指南」与「API 参考」、处理版本与弃用

## 工作流

```
文档任务:
- [ ] 1. 画文档信息架构（IA）
- [ ] 2. 定内容类型与目录约定
- [ ] 3. 实现文档路由与侧边栏数据源
- [ ] 4. 写/改一篇「快速开始」作为样板
- [ ] 5. 链到 API 参考与示例，检查死链
```

### 1. 文档 IA（推荐顶层）

```text
docs/
  getting-started/     # 快速开始、环境、认证
  guides/              # 任务型教程
  concepts/            # 核心概念与术语
  products/{slug}/     # 分产品指南
  api/                 # API 参考入口（或外链 Spec 站）
  changelog/           # 变更与迁移
```

原则：按**用户任务**分，不按内部团队或微服务仓库分。

### 2. 内容类型

| 类型 | 读者目的 | 必须有 |
|---|---|---|
| 快速开始 | 最短路径跑通 | 前置条件、步骤、可复制命令 |
| 指南 | 完成一类任务 | 场景、步骤、示例、下一步 |
| 概念 | 理解模型 | 定义、与相关概念对比、链到指南 |
| API 参考 | 查参数与错误码 | 从 Spec 生成或严格同步，不手写漂移 |

### 3. 实现约定

- 侧边栏由结构化数据生成（`_meta` / `sidebar.json` / frontmatter），禁止在布局里硬编码整棵树后忘记更新
- 正文支持标题锚点、代码复制、上一页/下一页
- API：优先 OpenAPI/异步生成页；指南内只放精简示例并链到参考页
- 版本：URL 或选择器二选一保持全站一致；弃用页顶部警告并给迁移链接

### 4. 样板「快速开始」最低标准

1. 目标结果（一句话）
2. 前置（账号、工具版本）
3. ≤ 7 个步骤，每步可验证
4. 完整可复制示例
5. 下一步链到核心指南或 API

### 5. 质量门

- [ ] 侧边栏顺序与阅读路径一致（开始 → 指南 → 参考）
- [ ] 无孤儿文（无入口）与死链
- [ ] 术语与产品名和门户其余页面一致
- [ ] 示例中无真实密钥
